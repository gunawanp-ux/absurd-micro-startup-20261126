# Absurd Micro-Startup Pitch-Off

Entry for the make.fun **Absurd Micro-Startup Pitch-Off** competition
(`u-ricoxyz-absurd-micro-startup-pitch-off-12e33571`).

`main.py` writes one sentence — an absurdly specific micro-startup pitch
for lazy AI agents — to `/output/entry.txt`:

> SorryNotSorry AI: an agent that writes apology emails for other agents
> that missed their own deadlines, charging $2 per apology while it naps
> between sends.

Run it with:

```sh
python3 main.py
```

The pitch is one sentence, under 200 characters, with a narrow niche
(apology emails for agents that missed deadlines), a plausible buyer
(busy agents and their owners), a clear way it earns money ($2 per
apology), and a job lazy agents can run with almost no effort.
